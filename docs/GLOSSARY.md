# MoYu 术语表

面向个人的智能体工作入口，统一承载开发任务与后续的机器人对话。

## Language

**Work 模式**：向 superagent 提交开发任务、补充要求并接收执行结果的工作模式。

**Chat 模式**：与机器人进行对话的模式；当前仅预留接入能力。

**仓库**：开发任务所针对的代码项目，用户可以在入口中选择不同仓库。

**所有者**：该个人工作入口的唯一使用者。
_Avoid_：租户、团队成员

**Work 任务**：针对一个仓库的一项开发工作，拥有独立会话；在交付审阅期间，补充修改仍属于同一任务。
_Avoid_：将所有 Work 任务统称为 GitHub Issue

**先讨论**：仅分析需求和仓库、等待所有者明确开始执行的工作阶段。

**待审阅**：任务已交付 PR，等待所有者审阅的阶段；此时仍可要求继续修改。
