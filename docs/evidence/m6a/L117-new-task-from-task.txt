## 5. 未验证 / 已知缺口

- 「独立 session id」在平台侧以新 conversation/task 和不复用来源 ticket 表达；真实 runtime session 只有在投递后
  才产生，本轮未起带模型的 runtime，因此没有 runtime session id 的原始值。
- 目标仓库的起点分支只做表单确认与非空校验；是否存在该分支由 runtime 在投递时解析（与原新建任务一致）。
- 他人仓库的拒绝是 API 层 404（无法在 UI 选择）；原文见 API 测试输出。
- 交付摘要取源会话最近一条 result/notice/progress 消息，截断到 600 字；不是新的持久字段。
