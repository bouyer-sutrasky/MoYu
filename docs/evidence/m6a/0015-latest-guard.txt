# 0015 非最新回滚守卫

代码 head（本文件据其产出）：
$ git rev-parse HEAD
ca9fe2d102a29e2bd1e90ad9442413c8edeabb31

被测文件：`packages/db/migrations/rollback/0015_late_gateway.down.sql`。
环境：隔离 PostgreSQL 16（`127.0.0.1:55432`），每次运行重建 `moyu_0015_guard_red` /
`moyu_0015_guard_legal` 两个一次性数据库；迁移用 `pnpm --filter @moyu/db db:migrate`（生产 0000–0015），
「更晚迁移」用**测试专用** fixture `packages/db/test/fixtures/0016_later_guard_fixture.sql`（不在生产迁移目录）。
复现脚本：`scripts/m6a/0015-guard-evidence.sh`；回滚用 `psql -v ON_ERROR_STOP=1 -f 0015_late_gateway.down.sql`，
因此拒绝时 psql 退出码非 0。未改 0015 生产迁移本体与 3082。

## 判定（期望 / 实际 / 结论）

| # | 期望 | 实际 | 结论 |
| --- | --- | --- | --- |
| 1 | 已应用更晚迁移时，回滚必须被拒绝 | RED：`down exit code: 0`，且 `message_id` 列、外键、索引与 ledger 行都被删除；GREEN：`ERROR: 0015 rollback refused: 1 later migration(s) are already applied`，`down exit code: 3` | RED 暴露缺口，GREEN 修复成立 |
| 2 | 拒绝时 schema 不变 | GREEN 回滚后 `artifacts` 仍有 `message_id:uuid`、`artifacts_message_id_messages_id_fk`、`artifacts_message_idx`；ledger `count(*) = 1` | 通过（DDL 前 RAISE，事务回滚） |
| 3 | 0015 为最新已应用迁移时，回滚照旧成功 | RED 与 GREEN 的 LEGAL 段均 `down exit code: 0`；回滚后列/外键/索引消失、ledger `count(*) = 0` | 通过（不是一律拒绝） |
| 4 | 守卫在生产路径 | 改动在 `0015_late_gateway.down.sql` 本体（`BEGIN; DO $$ ... RAISE EXCEPTION ... END $$; ... COMMIT;`），非测试判断 | 通过 |
