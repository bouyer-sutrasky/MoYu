### 3.1 为什么不使用 `-c diff.external=`（交接 §4 曾提出）

实测空值会被 git 当成空命令执行，diff 直接失败，因此改用文档化的 `--no-ext-diff`：

$ git -c diff.external= diff -- f.txt
error: cannot run : No such file or directory
fatal: external diff died, stopping at f.txt
exit code: 128

### 3.2 复现脚本（`/tmp/p1a-argv-proof.sh`）

```sh
#!/bin/sh
# Exact argv/env reproduction of what review.ts asks git to do.
set -u
root=$(mktemp -d); repo="$root/repo"; mkdir -p "$repo"; cd "$repo" || exit 1
git init -q -b main
git config user.email a@b.c
git config user.name t
printf 'alpha\nbeta\n' > tracked.txt
git add tracked.txt
git commit -qm init

write_helper() { # path sentinel
  printf '#!/bin/sh\nprintf ran >> %s\ncat "$2" 2>/dev/null || true\nexit 0\n' "'$2'" > "$1"
  chmod +x "$1"
}
write_helper "$root/diff-external.sh" "$root/ran-external"
write_helper "$root/textconv.sh" "$root/ran-textconv"
write_helper "$root/fsmonitor.sh" "$root/ran-fsmonitor"

git config diff.external "$root/diff-external.sh"
git config diff.m6a.textconv "$root/textconv.sh"
git config core.fsmonitor "$root/fsmonitor.sh"
printf 'tracked.txt diff=m6a\n' > .gitattributes
printf 'alpha\nbeta\ngamma\n' > tracked.txt

report() { # label then command
  label=$1; shift
  rm -f "$root"/ran-*
  echo "--- $label"
  "$@" >/dev/null 2>&1
  echo "exit=$?"
  found=0
  for f in "$root"/ran-*; do [ -e "$f" ] && { echo "sentinel: $(basename "$f")"; found=1; }; done
  [ "$found" = 0 ] && echo "sentinel: none"
}

echo "repo: $repo"
echo "git version: $(git --version)"
echo
echo "## unguarded reads (what collectChanges did before this change)"
report "git diff HEAD -- tracked.txt" git diff HEAD -- tracked.txt
report "git status --porcelain=v1" git status --porcelain=v1
echo
echo "## guarded reads (the argv review.ts now builds)"
report "git -c core.fsmonitor=false -c core.attributesFile=/dev/null diff --no-ext-diff --no-textconv HEAD -- tracked.txt" \
  git -c core.fsmonitor=false -c core.attributesFile=/dev/null diff --no-ext-diff --no-textconv HEAD -- tracked.txt
report "git -c core.fsmonitor=false status --porcelain=v1" \
  git -c core.fsmonitor=false status --porcelain=v1
echo
echo "## guarded read with an inherited GIT_EXTERNAL_DIFF and the minimal env review.ts passes"
rm -f "$root"/ran-*
env -i PATH="$PATH" TMPDIR=/tmp LANG=C LC_ALL=C \
  GIT_CONFIG_NOSYSTEM=1 GIT_CONFIG_GLOBAL=/dev/null GIT_ATTR_NOSYSTEM=1 GIT_TERMINAL_PROMPT=0 \
  GIT_EXTERNAL_DIFF="$root/diff-external.sh" \
  git -c core.fsmonitor=false -c core.attributesFile=/dev/null diff --no-ext-diff --no-textconv HEAD -- tracked.txt >/dev/null 2>&1
echo "exit=$?"
found=0
for f in "$root"/ran-*; do [ -e "$f" ] && { echo "sentinel: $(basename "$f")"; found=1; }; done
[ "$found" = 0 ] && echo "sentinel: none"
echo
echo "## the guarded diff still prints the real patch"
git -c core.fsmonitor=false -c core.attributesFile=/dev/null diff --no-ext-diff --no-textconv HEAD -- tracked.txt
rm -rf "$root"
```

  未采集任务详情触发自动采集时走的就是这条路径（`WorkspaceShell.tsx` 的 review effect）。

  超时按进程组回收、并发门控竞态都**未动**（下一轮）。
- 未验证：推送后的 GitHub CI（本轮结束时尚未触发）；A1–A8 整套证据未在本 head 重跑（按所有者口径随阶段收尾重跑）；

- 复现：`cd apps/supervisor && /opt/moyu-node24/bin/pnpm exec vitest run test/review.test.ts`。
