## 3. 实现判定

| 状态 | 旧 | 新 |
| --- | --- | --- |
| `File[]` / 上传 id / 错误 / 重试 | 组件级单一状态，切换会话不清 | 按 `owner + repository + conversation` 分桶（`AttachmentBucket`） |
| 迟到响应 | `setUploading(false)` / `setAttachmentError` 直接写全局状态 | 上传开始时记录桶版本；`settleAttachments(scope, version, …)` 只在版本未变时写回，进度标记只作用于该桶 |
| 上传目标 | 发送时用 `conversationIdRef.current`（切到 B 后是 B） | 发送开始时锁定当前会话的桶与 conversationId，上传与消息都用它 |
| 重试 | 每次重新上传 | 桶里记录 `uploaded`（文件键 → attachment id），重试复用已上传 id |
| 删除已选文件 | 只删 `File` | 同时移除该文件的已上传 id |
| 编辑/草稿 | 文本草稿与附件互不影响 | 不变；切回原会话能看到该会话自己的附件选择 |

代码位置：`apps/web/src/shell/Composer.tsx`（`AttachmentBucket`、`attachmentScopeKey`、
`changeAttachments`、`settleAttachments`、`patchAttachments`、`submit`）。
